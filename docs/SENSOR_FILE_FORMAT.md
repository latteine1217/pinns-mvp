# 📊 Sensor File Format Reference

## Overview

Sensor files generated by `scripts/generate_sensors_k500.py` are stored in `.npz` format with the following structure.

---

## 🔑 File Structure

### **Required Keys**

| Key | Type | Shape | Description |
|-----|------|-------|-------------|
| `sensor_x` | `float64` | `(K,)` | X coordinates of sensor points |
| `sensor_y` | `float64` | `(K,)` | Y coordinates of sensor points |
| `sensor_u` | `float64` | `(K,)` | U velocity at sensor points |
| `sensor_v` | `float64` | `(K,)` | V velocity at sensor points |
| `K` | `int64` | `()` | Number of sensors (scalar) |

### **Quality Metrics**

| Key | Type | Shape | Description |
|-----|------|-------|-------------|
| `condition_number` | `float64` | `()` | Matrix condition number (< 100 ideal) |
| `energy_ratio` | `float64` | `()` | Energy captured by POD modes (> 0.95 ideal) |
| `min_distance` | `float64` | `()` | Minimum distance between sensors |
| `mean_distance` | `float64` | `()` | Mean distance between sensors |

### **Metadata**

| Key | Type | Shape | Description |
|-----|------|-------|-------------|
| `K_requested` | `int64` | `()` | Originally requested K |
| `grid_shape` | `int64` | `(2,)` | Original DNS grid shape `[Ny, Nx]` |
| `snapshot_time` | `float64` | `()` | DNS snapshot time |
| `n_modes_used` | `int64` | `()` | Number of POD modes used |
| `sensor_indices` | `int32` | `(K,)` | Flattened indices in original grid |
| `grid_x` | `int32` | `(K,)` | Grid X indices (0-based) |
| `grid_y` | `int32` | `(K,)` | Grid Y indices (0-based) |

## 📝 Usage Examples

### **Load and Inspect**

```python
import numpy as np

sensors = np.load('data/jhtdb/sensors_kf8_deim_K100.npz')

# Check available keys
print("Available keys:", list(sensors.keys()))

# Access sensor coordinates
x = sensors['sensor_x']  # ✅ Correct
y = sensors['sensor_y']  # ✅ Correct

# Common mistake (deprecated):
# coords = sensors['coords']  # ❌ KeyError: 'coords' not in file
```

### **Extract Sensor Locations**

```python
import numpy as np
import matplotlib.pyplot as plt

sensors = np.load('data/jhtdb/sensors_kf8_deim_K100.npz')

# Extract coordinates
x = sensors['sensor_x']
y = sensors['sensor_y']

# Plot sensor distribution
plt.figure(figsize=(8, 8))
plt.scatter(x, y, c='red', marker='x', s=50)
plt.xlabel('x')
plt.ylabel('y')
plt.title(f"Sensor Distribution (K={sensors['K']})")
plt.grid(True, alpha=0.3)
plt.show()
```

### **Check Quality Metrics**

```python
import numpy as np

sensors = np.load('data/jhtdb/sensors_kf8_deim_K100.npz')

print(f"📊 Sensor Configuration Summary")
print(f"  Total sensors: {sensors['K']}")
print(f"  Condition number: {sensors['condition_number']:.2f}")
print(f"  Energy ratio: {sensors['energy_ratio']:.4f}")
print(f"  Min distance: {sensors['min_distance']:.4f}")
print(f"  Mean distance: {sensors['mean_distance']:.4f}")

# Quality checks
if sensors['condition_number'] < 50:
    print("  ✅ Excellent conditioning (< 50)")
elif sensors['condition_number'] < 100:
    print("  ✅ Good conditioning (50-100)")
else:
    print("  ⚠️ Warning: High condition number (> 100)")

if sensors['energy_ratio'] > 0.95:
    print("  ✅ Excellent energy capture (> 0.95)")
elif sensors['energy_ratio'] > 0.90:
    print("  ✅ Good energy capture (0.90-0.95)")
else:
    print("  ⚠️ Warning: Low energy capture (< 0.90)")
```

## 🔧 Backward Compatibility Note

**Old Format (deprecated)**:
```python
# Pre-Nov 2025 format (if you have old files)
coords = sensors['coords']  # Shape: (K, 2)
x = coords[:, 0]
y = coords[:, 1]
```

**New Format (current)**:
```python
# Current format (Nov 2025+)
x = sensors['sensor_x']  # Shape: (K,)
y = sensors['sensor_y']  # Shape: (K,)
```

## ⚠️ Common Errors

### **KeyError: 'coords is not a file in the archive'**

**Cause**: Trying to access deprecated `'coords'` key.

**Solution**:
```python
# ❌ Old code
sensor_coords = sensors['coords']

# ✅ Fixed code
sensor_x = sensors['sensor_x']
sensor_y = sensors['sensor_y']
```

### **IndexError when plotting**

**Cause**: Using 2D array indexing on 1D arrays.

**Solution**:
```python
# ❌ Old code
plt.scatter(sensor_coords[:, 0], sensor_coords[:, 1])

# ✅ Fixed code
plt.scatter(sensor_x, sensor_y)
```
